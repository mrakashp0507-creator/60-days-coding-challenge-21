# Day 21 - Sprint Challenge Reflection

## What I Learned

This challenge helped me understand that many common programming operations can be implemented manually using fundamental data structures and algorithms.

The recursion problem showed me how a problem can be divided into smaller versions of itself.

The stack problem helped me understand the LIFO principle more clearly.

---

## Challenge 1 - Recursion

Finding the largest element without using max() required manual comparison.

The important part was understanding the difference between:

- Base Case
- Recursive Case

The function keeps moving through the array and then compares values as the recursive calls return.

---

## Challenge 2 - Stack

For string reversal, I used a stack.

Each character was pushed into the stack and then removed using pop().

Because stacks follow:

    Last In - First Out

the characters naturally came out in reverse order.

---

## What Was Difficult?

The main challenge was avoiding built-in helper functions.

Instead of relying on:

    max()
    sum()
    min()
    sort()

I had to think about how these operations work internally and implement the logic myself.

## Key Lesson

Built-in functions make programming convenient, but understanding the logic behind them makes it easier to debug and design algorithms.

The main lesson from this sprint is:

"Don't just use an algorithm. Understand how it works."
